# odin-recipes
a simple website for favorite recipes. The first of the Odin Project assignments, should look different once the CSS lessons 
begin. I will demonstrate very basic HTML skills with this project. Setting up a boiler plate, creating lists, providing absolute 
and relative links, adding images to the web pages.
